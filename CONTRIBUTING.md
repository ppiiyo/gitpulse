# Contributing to GitPulse

Thanks for helping make GitHub rankings more honest.

## Ways to contribute

1. **Star & share** — the simplest way to grow the project
2. **Open an issue** — bugs, ranking edge cases, category ideas
3. **Improve methodology** — debate weights in `docs/methodology.md`
4. **Pull requests** — UI polish, seed coverage, docs

## Dev setup

```bash
npm install
npm run dev
```

Optional seed (needs `GITHUB_TOKEN`):

```bash
npm run seed
```

## PR guidelines

- Keep the ranking formula **transparent** — no hidden magic scores
- Prefer small, focused PRs
- Match existing dark minimal UI
- Don’t commit secrets or large binary blobs

## Code of collaboration

Be direct, kind, and specific. Disagreement about weights is welcome; personal attacks are not.
